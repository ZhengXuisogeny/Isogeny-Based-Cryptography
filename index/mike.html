High-dimensional Isogeny-based Cryptography

  1. CDS-Hash Function（2020）

    Wouter Castryck, Thomas Decru, and Benjamin Smith proposed a new hash function constructed using two-dimensional Abelian varieties.

    Hash Functions From Superspecial Genus-2 Curves Using Richelot Isogenies

  2. Two-Dimensional SIDH(2019)

    E. V. Flynn and YanBo Ti proposed two-dimensional SIDH.

    Genus Two Isogeny Cryptography

  3. MIKE (2026, Preprint)

    Andrea Basso and coauthors presented MIKE, a non-interactive key exchange based on the action of rank-2 Hermitian modules on supersingular elliptic curves, and gave a constant-time C implementation. The fast parameter set targeting NIST security level I uses 80-byte public keys.

    MIKE: a fast and compact post-quantum NIKE

  4. Shimura Class Group Actions on Oriented Superspecial Abelian Varieties (2026, Preprint)

    Wouter Castryck, Bogdan Adrian Dina, Péter Kutas and Gioella Lorenzon studied the action of the Shimura class group on superspecial principally polarized abelian varieties with a complex multiplication (CM) orientation. They used higher-dimensional isogenies to represent CM orientations and gave a method for computing the action in the restricted effective group action model.

    Post-quantum commutative group actions from oriented superspecial abelian varieties
